## What I'm working on

- **Conversational applications for large companies** (healthcare, corporate benefits, fitness) on the **Blip** platform: chatbot flows, Script V2 (JavaScript), and their integrations with REST APIs, CRMs and internal systems.
- **Backend services and integrations** in **Node.js, TypeScript and Firebase**, plus maintenance of **C#/.NET** APIs running on client infrastructure.
- **AI engineering for developer workflows**: agent instructions, skills and guardrailed tooling that let an LLM agent specify, build, audit and document chatbot flows — see [`blip-sdd`](https://github.com/Matheuspgonsalves/blip-sdd).
- **Data structures & algorithms** in TypeScript, from scratch, with tests.

## Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**blip-sdd**](https://github.com/Matheuspgonsalves/blip-sdd) | Agent kit for **Spec-Driven Development** of Blip chatbots. A single LLM agent routes requests to 10 skills (spec → design → tasks → flow JSON, troubleshooting, test checklists, daily reports, read-only API queries). Includes guardrail scripts: mechanical JSON audit, safe-save with backup/rollback and block-loss protection, a read-only API client, and a pre-commit hook that blocks leaked credentials. | Node.js · AI agents (Antigravity/Gemini) · Markdown specs · Git hooks |
